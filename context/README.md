# Workspace Live Context

本目录只保存 Public-safe、provider-neutral 的 Context 说明与索引。飞书 folder/document ID、私有 URL、provider revision 和本机 Registry 不进入 Git。

- `HUB_INDEX.md`：策划入口内容源，不包含私有 provider 链接。
- `CAPABILITY_WORKFLOW_SKILL_INDEX.md`：Capability、Workflow 与 Skill 导航。
- 动态 Task/Status/Handoff 由 `git-current-state` generator 在 Host-local pack 中生成，不把 snapshot 当 canonical。
- 飞书协作草稿通过 Memory Candidate/Review 进入 Git，不直接写入本目录。
