# 数值知识库

当前根目录为 `AI-Workspace/projects/cr/`。目录构建与校验默认不计算或比对文件哈希；旧清单已有哈希仅保留历史来源。生成物可重建，源表默认只读。

本目录是面向人和 AI 的轻量检索层，正文与业务数据仍以源文档为准。

人工整理入口：

- `策划源表导航.xlsx`：按业务区域标出策划源表的推荐入口、配置页、历史页和整理建议。
- `../数值文档`：当前有效的规范、系统、玩法和分析文档。
- `../数值文档/04_飞书归档`：飞书原始正文和附件来源说明。

自动生成文件：

- `数据目录.md`：数据源概览、文件数和使用说明。
- `工作簿目录.csv`：每个工作簿的大小、哈希、Sheet 和表头预览。
- `工作簿结构.json`：工作簿与 Sheet 的结构化元数据，供 AI/脚本检索。
- `同步清单.json`：最近一次同步的来源、目标和文件哈希。

更新命令：

```powershell
python .\数值策划\工具\build_catalog.py
```

TRAE 使用建议：

1. 将整个仓库作为项目打开，让代码、文档、目录和 Skill 一起被索引。
2. 使用 `.trae/rules/numerical-design.md` 约束固定行为。
3. 使用 `.agents/skills/cr-numerical-design` 提供按需加载的数值工作流。
4. 大体量 Excel 通过本目录的 CSV/JSON 摘要检索，命中后再读取具体源表，降低上下文噪声。
5. 企业知识库如需上传，优先上传数值文档和本目录生成物；原始 Excel 是否上传需按权限和敏感级别评估。
