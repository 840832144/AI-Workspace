# 数据源

日期卡包资料包中的 trunk/dev r6880 配置附件是该次研究来源，保留在原资料包内；它们不属于日常同步源，不代表当前配置，也不重建退役的程序配置导出快照。资料同步目标以 CR 项目目录为基准。

| 目录 | 定位 | 是否在此编辑 |
|---|---|---|
| `策划源表` | 数值策划维护的业务工作簿快照 | 原则上否，回原始工作目录修改后同步 |

同步规则见 `../工具/config/data_sources.json`。每位策划通过 `CR_DESIGNER_WORKBOOKS_DIR` 配置自己的本机源表目录，路径不进入 SVN。运行同步前默认 dry-run；同步不会自动删除目标中多出的文件。

程序配置不复制到本资源库。分析或复核配置时，直接只读目标 `dev` 或 `trunk`
工作副本；先用 `svn info` 核对项目、完整 URL 与 revision，并在报告中记录这些信息。

权威级别：

1. 正式配置制作/发布链路；
2. 目标 `dev` / `trunk` 版本化配置；
3. 策划原始工作目录；
4. 本仓库策划源表副本；
5. 自动生成的知识库目录。
