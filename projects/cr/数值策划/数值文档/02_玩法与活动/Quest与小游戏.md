# Quest 与小游戏

## 通用验收维度

开放条件、次数/体力、单局投入、奖励期望、失败补偿、活动周期、玩家分层和主经济影响。

## 工作簿入口

| 玩法 | 推荐先看 | 配置/输出页 |
|---|---|---|
| Quest 主系统 | `quest数值.xlsx`：`cashFrenzy数值`、对应版本体验表 | `QuestPickaxeGet`、`QuestGetLevel`、`QuestBPTask`、`CommonBPLevel` 等 |
| 宝藏矿工 | `宝藏矿工.xlsx`：`数值体验表`、`bet配置` | `QuestMinerDropItem`、`QuestMinerMap`、`QuestMinerStageReward` 等 |
| 幸运 7 | `幸运7数值.xlsx`：`数值体验表`、`奖励配置`、`bet配置` | `StrikeLuckyRound`、`StrikeLucky` |
| 弹球 Quest | `弹球quest数值 (2).xlsx`：`数值体验表`、`WeightCalculate` | `QuestPlinkoWeight`、`QuestPlinkoStageReward` |
| 疯狂探险 | `疯狂探险.xlsx`：`数值体验表`、`机器列表`、`bet对应表` | `QuestFrenzyMission` |
| 薯片 | `薯片数值.xlsx`：`数值体验表`、`难度系数`、`档位膨胀` | `SnackDropItemCfg`、`SnackPassReward`、`SnackAddLuck` 等 |

> 薯片与幸运7 的玩法闭环和每张配置表用途，见 [薯片与幸运7（777）玩法与配置](薯片与幸运7（777）玩法与配置.md)。
> 拳击的玩法闭环和每张配置表用途，见 [拳击（Boxing）玩法与配置用途说明](拳击（Boxing）玩法与配置用途说明.md)。
> 挖矿的玩法闭环和每张配置表用途，见 [挖矿（Miner）玩法与配置用途说明](挖矿（Miner）玩法与配置用途说明.md)。
