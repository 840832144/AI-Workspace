# 老虎机与调控

## 机台建模最小交付

- 输入参数、下注区间和玩家分层；
- 奖励结构、命中分布、RTP 和波动描述；
- 仿真方法、随机种子策略和样本量；
- 目标区间、边界用例和验收结论；
- 可复跑的 Python 3 脚本及运行说明。

## 调控最小交付

- 业务目标与不可突破的约束；
- 分层条件、上下限、持续时间和退出条件；
- 灰度、回滚和线上监控指标；
- 与程序配置字段的对应关系。

程序侧配置直接在目标 `dev` 或 `trunk` 工作副本中按 `Slots`、`Casino`、`Rtp`
等关键词只读查询，并记录 SVN URL 与 revision；任何修改必须回到正式配置发布链路。
