# 挖矿（Miner / 宝藏矿工）玩法与配置用途说明

> 状态：挖矿当前配置大概率是测试数据；本文沉淀“玩法闭环 + 每张表干什么用”，配置数值待需求定稿后再改。

## 一、玩法闭环

### 1. 地图与障碍物

- 每关开始，地图 6×10 格子被不同障碍物覆盖。
- 障碍物：普通砖块（镐/炸弹/钻头可击碎）、宝石（镐/炸弹/钻头可击碎）、特殊砖块（只有钻头可击碎）。
- 宝石即“钻石”，实际收集的是红、绿、蓝三种宝石。

### 2. 点击交互

- 点击地图：正前方路径被清空后，矿工自动沿轨道向前移动，镜头平滑推进。
- 点击普通砖块：矿工靠近砖块四面中无障碍的一面（多面无障碍取最近），消耗 1 个镐击碎砖块。
- 点击特殊砖块：提示不能被击碎。
- 点击宝石：不消耗道具，矿工靠近后收集宝石。
- 拖动道具：范围击碎任意位置砖块。
  - 炸药：横向清除选中砖块直线前的 1×5 障碍物，特殊砖块不能被选中或清除（遇到即断）。
  - 重型钻头：横向清除选中砖块所在直线上的所有障碍物。
  - 道具不足弹购买：炸药消耗 5 个凿子、重型钻头消耗 15 个凿子。
- 道具体系共 4 种：凿子（镐）、炸药（1×5）、重型钻头（整行）、炸弹（3×3，掉落获得）。
  - `QuestInitItem` 的 215020 / 215021 / 215022 = 凿子 / 炸药 / 钻头（Item 表对应 Pickaxe / Explosives / DrillBit）。

### 3. 奖励

- 基础奖励：空、金币、卡包、建造币。
- 道具奖励：炸弹，以炸弹出现点为中心清除 3×3 范围内所有普通砖块。

### 4. Jackpot

- 同花色宝石凑齐 3 个获得 jackpot。
- 收集完成后播放领奖和刷新动画后重置。
- 活动期间内 jackpot 不受领取次数限制。
- 收集任务重新刷新后奖励提升、难度提升。

### 5. 地图关卡

- 玩家选择关卡宝箱、矿工靠近宝箱即通关，获得通关奖励。
- 关卡循环：第三关结束后从第一关重新开始（重置地图布局）。
- 所有关卡配置通关后，按最大 `round` 一直循环。

### 6. Pass 与礼包

- Pass：本玩法暂不涉及（先跳过，可能没有该功能）。
- 抽奖道具礼包：金币 + 道具打包，可重复购买。

## 二、每张配置表是做什么用的

### 1. 挖矿专属配置

| 表 | 干什么用 |
|---|---|
| `QuestMinerMap` | 地图布局：按关卡 + 行配置每格障碍物 id。6 行 × 10 列；1=普通砖块、2=特殊砖块、9/10/11=红/绿/蓝宝石（对应 `QuestJackpotCfg` 的 id）。 |
| `QuestMinerDropItem` | 击碎障碍物的掉落：按关卡 + 剩余障碍物数配置。字段含义：`EmptyProb`=空、`BombProb`=炸弹、`CashNum`=建设币、`ChipProb`+`chipNum`=金币（priceType=17 美金金币）、`CardPageProb`+`CardPageItemId`=卡包。 |
| `QuestMinerStageReward` | 通关奖励：按关卡 + 轮次（`round`）配置通关宝箱奖励；`round` 递增对应“循环后奖励/难度提升”，达到最大 `round` 后一直按最大 `round` 循环。 |

### 2. 掉落与兑换（questType=9，复用通用表）

| 表 | 干什么用 |
|---|---|
| `QuestPickGet` | 按 bet 档配置掉落概率和单次掉落积分/经验（挖矿用 questType=9）。 |
| `QuestPointsCheatSheet` | 把 bet 换算成活动积分：按活动类型、等级、VIP 给系数。 |
| `QuestGetLevel` | 积分累计升级、给多少道具（镐/工具）和上限墙；挖矿当前只有占位行。 |
| `QuestInitItem` | 活动初始道具数量和单道具兑换金币数（挖矿 215020 凿子 / 215021 炸药 / 215022 钻头）。 |
| `QuestPicksDifficulty` | 掉落/兑换的阶梯难度倍数。 |

### 3. 宝石 Jackpot

| 表 | 干什么用 |
|---|---|
| `QuestJackpotCfg`（Type=9 宝藏矿工） | 定义挖矿三种宝石（红/绿/蓝，id 9/10/11）的收集数量和基础奖励；地图里 9/10/11 引用这里。 |

### 4. 礼包

| 表 | 干什么用 |
|---|---|
| `QuestItemPack` | 活动通用道具礼包（商品 id、价格、道具数量）；挖矿“金币 + 道具”礼包复用此表。 |

### 5. 活动总控、通用资源与消耗成本

| 表 | 干什么用 |
|---|---|
| `Activity`（id=1036） | 挖矿活动总开关、时间档期、解锁条件、弹窗、图标。 |
| `SysUnlock` / `PopControl` / `PopList` | 解锁条件、相关弹窗。 |
| `ModuleNames` / `Item` / `LanguageDesc` | 模块、道具、多语言名称与资源引用。 |
| `PriceCheatSheet` | 价格基准表（各等级/VIP 的 1 美金金币值，17 型奖励金额查表）。 |
| `SlotsCasinoBetList` / `SlotsCasinoResultSwitchStrategy` | bet 档位与 RTP 切换（决定玩家 Spin 净消耗，间接影响掉落成本）。 |

> 炸药（1×5）和重型钻头（整行）的清除规则写在代码逻辑里，不需要配置表。
