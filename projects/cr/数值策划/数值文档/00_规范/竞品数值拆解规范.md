# 竞品数值拆解规范

> 用途：统一竞品数值拆解的流程、章节、口径与验收标准，覆盖主玩法（Slot）、建造/成长、小游戏、任务/Pass、免费/日历、付费体系与长周期。
> 原则：事实与假设分开、素材可追溯、结果可复算、未知口径标"待确认"、竞品结论不得直接作为 CR 配置结论。
> 配套：`竞品数值拆解模板.md`（每款新游戏复制一份填空）；`数值体验需求话术模板.md`（向 AI 下达复算需求）；`术语表.md`（主术语唯一）。

## 0. 适用范围与目标

- 适用游戏类型：Slot+Tycoon 混合（Top Tycoon、Cash Frenzy 类）、建造+小游戏混合等资源循环型产品；其他类型只取相关章节。
- 拆解目标：每份报告必须回答以下五个问题：
  1. 经济系统循环是什么？每一层（操作/会话/日/周·活动/长周期）的源和汇是什么？
  2. 每个周期的消耗与付费深度是多少？首个付费压力点在哪？
  3. 每个 BET 档位的消耗、返还、波动与解锁条件是什么？
  4. 给定任意付费金额，波动体验曲线如何变化（与 0 付费基线对比）？
  5. 哪些观察可作为迁移结论，需要 CR 验证？

## 1. 拆解阶段（P0–P6）与通过门槛

| 阶段 | 输入 | 输出 | 通过门槛 |
|---|---|---|---|
| P0 素材准入 | 录屏、截图、商店页、购买前后窗、配置快照 | 素材清单 + 证据分级 + 缺口清单 | 每类结论都有可追溯素材；素材边界写入报告 |
| P1 事件账 | 固定帧（1 fps）逐帧标注 | 原始事件账：时间、界面、资源变化、事件 | 事件闭环率 ≥ 95%；关键帧全部用 FrameIndex 锚定 |
| P2 机制还原 | 事件账 | 全局资源循环图、三套口径、模块清单 | 每个模块至少 1 条 A/B 级证据 |
| P3 数值拟合 | 事件账 + 节点观察 | BET 档位表、结果树、概率与返还分布、建造成本曲线 | 每关键切片 ≥ 500 Spin；不足则只出方向性结论 |
| P4 体验模拟 | 拟合参数 + 场景假设 | 0 付费主轨、波动体验曲线、节点表 | 固定种子复算一致；余额/进度与实测对齐 |
| P5 付费深度 | 商品表、购买前后窗 | 付费档位体验曲线、每 USD 价值、购买前后差异 | 有同账号真实购买前后窗口 |
| P6 迁移结论 | 以上全部 | 可迁移点清单 + CR 验证状态 | 每条结论过 CR 分层/单位/周期/主经济验证 |

## 2. 统一口径（所有报告强制）

### 2.1 三套资源口径必须分开

1. 原生单位：金币、能量、进度、门票、活动代币各自记账，不跨单位相加。
2. 自返还率：直接返还能量 ÷ 该 Spin 能量消耗，只回答"能量能不能续"。
3. 标准化总返还：只有建立可靠锚点（商店同档兑换、可逆兑换、稳定边际价值）后才可计算；锚点未确认时只作场景假设，标注"待确认"。

### 2.2 RTP 口径

- 各模块按"对投注额的 RTP 百分点"展示，直接相加 = 总经济 RTP，不做归一化。
- 观察频率 ≠ 服务端真值。概率一律附样本量 n 与 95% Wilson 区间。

### 2.3 证据分级

| 级别 | 定义 | 示例 |
|---|---|---|
| A | 界面数值与资源变化双向可核 | Spin 前后余额差 = 命中奖励 |
| B | 单界面显示，无前后窗口 | 礼包标"Up to 2.06K 能量" |
| C | 推断或场景假设 | 金币↔能量锚点、稳定期 RTP |

### 2.4 结果树

- 每个 Spin 按互斥主类归账：纯金币 / 混合奖励 / Attack / Credit Grab / Shield / 纯进度 / 空奖 / 大奖。
- 复合资源保留在流水明细，主类统计不重复计数。

### 2.5 波动指标定义

| 指标 | 定义 | 单位 |
|---|---|---|
| 余额轨迹 | 逐操作余额序列（含付费注入点） | 资源/操作 |
| 最大回撤 | 峰值到谷值的最大跌幅 | 资源 或 % |
| 分位数带 | 多次模拟的 P10/P50/P90 余额曲线 | 资源 |
| 连输长度 | 连续无正向返还的操作次数 | 次 |
| 谷值次数 | 余额跌破阈值（默认 0.5×当前 Bet）的次数 | 次 |
| 波动系数 | 逐操作余额变化标准差 ÷ 均值 | 无量纲 |
| 破产事件 | 余额不足以完成下一次操作 | 次 |

## 4. 各章要求

### 4.1 报告信息（第 0 章）

| 字段 | 要求 |
|---|---|
| 素材清单 | 每段素材：ID、时长、账号、地区、日期、版本 |
| 样本口径 | 账号阶段、付费状态、BET、成长段 |
| 明确排除 | 本报告不回答的问题（如服务端真值、美术） |

### 4.2 核心结论先行（第 1 章）

| 维度 | 结论 | 状态 |
|---|---|---|

状态只能是：已确认 / 方向性 / 不可识别。结论后必须引用依据。

### 4.2.1 体验总览（节点进度快照）

- 每个消耗时点一行（累计 Spin / 能量 / 金币口径统一并写明），列出：等级、已解锁 BET 倍率、金币/能量余额、建造任务、主进度、区域、小游戏/活动次数、任务/Pass 完成、累计付费、波动事件（低谷/破产/付费曝光）。
- 等级与膨胀（BET 倍率）解锁单独成表：等级门槛 → 解锁内容（BET / 系统 / 建造区域），标注证据分级。
- 本表是跨模块节点对齐的最终口径：与各模块表冲突时以本表为准并注明差异。

### 4.3 全局资源循环（第 2 章）

- 必须给出 mermaid 资源循环图，每条边标注资源类型与方向，来源(S)/消耗(K) 标注。
- 分层循环单独成节：操作层 / 会话层 / 日层 / 周·活动层 / 长周期层。
- 每层给"源-汇-回流"表：

| 层 | 源(Source) | 汇(Sink) | 回流 | 层内净产出 |
|---|---|---|---|---|

### 4.4 主玩法拆解（第 3 章）

必填内容：
1. BET 档位表（见下）。
2. 结果树 + 概率表，附 n 与 Wilson 区间。
3. 返还分布：均值/P50/P90/P99/最大值、命中率、空奖率。
4. 波动特征：连输、回撤、破产速度。
5. 档位切换策略：新手激进期、持金比例、等级解锁限制。

BET 档位表：

| 档位 | 每Spin消耗 | 解锁条件 | 样本n | 金币命中率 | 返还均值/P50/P90 | 能量自返还率 | 波动特征 | 结论 |
|---|---:|---|---:|---:|---|---|---|---|

要求：各档位不得跨样本合并；每个档位必须给样本量；样本不足 500 只写方向性。

### 4.5 成长/建造循环（第 4 章）

- 成本曲线：任务/地块价格 vs 序号，给出拟合（分段线性/幂律）与拟合质量。
- 目标曲线：主进度目标值 vs 成长段；节点奖励 vs 目标值。
- 完成周期：达到各里程碑所需 Spin 数/天数（0 付费与付费两种口径）。
- 必须回答：启动资金从哪来；首次"金币不足"出现在第几次操作；后续枯竭频率。

### 4.6 小游戏与活动（第 5 章）

每个模块一张表：

| 字段 | 内容 |
|---|---|
| 入场资源 | 门票/代币/道具，获取途径与概率 |
| 单局消耗 | 资源数 |
| 规则与结构 | 层数、棋盘、保底、重置规则 |
| 返还分布 | 均值/P50/大奖 |
| 期望值 | 消耗 vs 期望返还（样本不足标"待补"） |
| 经济占比 | 对投注额 RTP 百分点 |

### 4.7 任务/Pass/免费/日历（第 6 章）

- 任务图谱：类型、配额、日刷新、奖励。
- Pass：周期、经验来源、等级奖励、付费线。
- 免费/日历：类型、发放时机、跨日召回作用。

### 4.8 付费体系（第 7 章）

商品表：

| 商品 | 价格 | 标称价值 | 到账口径(Up to/TOTAL/即时) | 实际到账 | 触发时机 | 是否购买 |
|---|---|---:|---|---|---|---|

- 价格阶梯：相邻档位价差、每 USD 资源、递增幅度。
- 付费深度：各档位累计付费对应的可玩时长/进度推进。
- 首次付费压力点：弹窗与破产必须区分，不能混写。
- "Up to / TOTAL" 标称值不得当作即时到账或汇率锚点。

## 5. 波动体验曲线拟合规范（核心能力）

### 5.1 目的

输入任意付费金额（如 $0 / $4.99 / $9.99 / $19.99 / $49.99 / $99.99），模拟并显示该档位的波动体验曲线，与 0 付费基线叠加对比，回答"多付 X 美元买到了什么"。

### 5.2 输入参数

| 参数 | 必填 | 说明 |
|---|---|---|
| 玩家画像 | 是 | VIP、等级、地区、付费状态 |
| 初始资源 | 是 | 金币、能量、道具 |
| 汇率锚点 | 是 | 无锚点则标"待确认"，只作场景假设 |
| 模拟周期 | 是 | 天 × 分钟/天 × 秒/操作 |
| BET 策略 | 是 | 前 N 级激进、之后按持金比例、受解锁限制 |
| 模块 RTP | 是 | 各模块百分点，直接相加 = 总经济 RTP |
| 结果树分布 | 是 | 从事件账拟合 |
| 建造成本曲线 | 是 | 从节点拟合 |
| 付费注入 | 是 | 见下 |

付费注入必须记录：

- 金额（USD 或地区币种）；
- 到账资源与口径（Up to / TOTAL / 即时）；
- 触发时机（破产点 / 里程碑 / 主动购买 / 首充弹窗）；
- 是否可重复购买。

### 5.3 方法

- Monte Carlo：固定种子，N ≥ 1000 用户，逐操作推进。
- 奖励分布：事件账经验分布或对数正态拟合，用 P10/P50/P90/P99 校准实测。
- 建造成本：节点 → 分段线性/幂律拟合，报告拟合质量。
- 付费注入：按触发时机注入；"Up to" 标称值不得按即时到账计算。

### 5.4 必出图表

1. 余额轨迹叠加图：0 付费 + 各付费档，付费点标红，按天/阶段分区。
2. 分位数带图：P10/P50/P90。
3. 连输长度与最大回撤分布。
4. 建造完成进度 vs 时间（各付费档）。

### 5.5 必出指标表

| 指标 | $0 | $4.99 | $9.99 | … |
|---|---:|---:|---:|---:|
| 期末余额（P50） |  |  |  |  |
| 最大回撤 |  |  |  |  |
| 谷值次数 |  |  |  |  |
| 破产事件 |  |  |  |  |
| 建造任务数 |  |  |  |  |
| 达到下一付费点时间 |  |  |  |  |
| 每 USD 可玩时长 |  |  |  |  |

### 5.6 验收

- [ ] 固定种子可复算，另一位策划用同一命令得到相同结果。
- [ ] 与实测节点对齐（余额/进度在容限内）。
- [ ] 到账口径正确，"Up to" 未按即时到账计算。
- [ ] 付费曲线差异可解释（拉到余额、推进进度、减少谷值）。
- [ ] 边界已测：0 付费、极端大 R、连续破产。

## 6. 指标清单

### 6.1 必填指标

- 素材：素材 ID/时长/账号/地区/版本、证据分级、缺口清单。
- 单操作级：BET、每 Spin 消耗、结果树概率、命中率、空奖率、返还均值/P50/P90/P99/最大值、能量自返还率。
- 会话级：会话时长、Spin 数、净产出、低谷深度与次数、破产触发、付费曝光时机。
- 日级：任务配额、日历/免费奖励、能量上限与恢复、日净产出、留存钩子。
- 周·活动级：活动代币/门票、小游戏返还、排行榜、Pass 周期返还。
- 长周期：主进度目标曲线、建造成本曲线、节点奖励、毕业成本、收集完整度。
- 付费：首个付费压力点、商品表、价格阶梯、每 USD 资源、购买前后体验差。
- 波动体验：余额分位带、最大回撤、谷值次数、连输长度、破产事件、付费曲线对比。
- 体验总览：消耗时点快照（等级、已解锁 BET、各模块进度、累计付费、波动事件）与等级/BET 解锁里程碑。

### 6.2 选填指标（其它可作为指标）

1. 首小时：time to first paywall、首次能量耗尽时间。
2. 奖励密度：命中率、每 100 Spin 奖励次数。
3. 分布形状：偏度、头部集中度、大奖占比。
4. 能量经济：恢复速率、上限、直购价、溢出。
5. 任务图谱：类型、配额、日刷新。
6. 收集系统：卡包概率、重复率、完成成本。
7. 社交：邀请奖励阶梯、成功转化率。
8. 地区定价：价差、汇率、价格锚。
9. 版本漂移：事件期 vs 平日、版本差异。
10. 保底调控：破产调控参数、触发条件、冷却。
11. 转化漏斗：曝光→点击→购买（素材支持时）。
12. 消费上限：每日/每周限购。
13. 内容耗尽：全收集天数、毕业成本。
14. 留存钩子：连续登录、限时奖励、倒计时。
15. 心理账户：能量计价 vs 金币计价。

## 7. 素材准入与补采门槛

| 素材类型 | 准入要求 | 通过条件 |
|---|---|---|
| 新手流程 | 单账号连续覆盖 | 至少完整首日 |
| 概率切片 | 每主要账号段×BET | 每切片 ≥ 500 Spin，总体 ≥ 2000 |
| 大奖概率 | 同口径连续 | ≥ 10000 Spin |
| 小游戏 | 3 个难度段 | 随机模块每段 ≥ 100 次 |
| 付费前后 | 同账号购买前后 | 各 100/300 Spin，记录真实到账 |
| 锚点 | 商店同档、可逆兑换或稳定边际价值 | 有双向兑换证据 |
| 多账号 | 账号阶段/地区/付费状态分开 | 不跨账号拼生命周期 |
