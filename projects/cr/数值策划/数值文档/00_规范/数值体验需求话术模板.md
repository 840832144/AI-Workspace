# 数值体验需求话术模板（通用版）

> 用途：自有项目数值体验复算、竞品精品拆解、AI 辅助数值推导  
> 用法：复制本模板，替换 `[方括号]` 内容后即可作为需求发出；也可以直接使用第十一章的“一段式速查话术”。  
> 原则：事实与假设分开、配置版本可追溯、结果可复算、未知口径标“待确认”。

---

## 一、一句话需求

输出 `[项目代号/竞品名]` 的数值体验报告：以 `[玩家画像]` 为模拟对象，从 `[初始状态]` 开始连续体验 `[N]` 天（每日 `[X]` 分钟、单次操作 `[Y]` 秒），覆盖 `[主玩法 / 建造 / 活动 / 任务 / 免费奖励 / 通行证 / 长周期收集]` 等模块，给出可复算的 Python 3 脚本、分段节点体验表、模块 RTP 构成和可视化页面，并说明付费节点与付费后的体验差异。

## 四、体验周期与节奏

- 单日时长上限：`[90]` 分钟；连续：`[3]` 天；单次操作：`[3]` 秒；总操作：`[N]` 次。
- 分段展示：前 `[10]` 次逐次一行，之后按 `[50 / 100 / 500]` 或按日/阶段合并；等级按分段展示，不逐级罗列。
- 每个模块单独出一张体验表；长周期系统（如卡包/收集）需覆盖到完成终点，不能只看首日。

## 五、核心循环公式口径

1. **初始资金**：`[来源]` → `[第一次可操作时机]`。
2. **消耗与返还**：每次操作 Bet = `[策略]`；返还 = `[稳定期 RTP]`% + 各奖励模块。
3. **Bet 策略**：新手期 `[激进]`；之后按持金 `[1/100 ~ 1/200]` 选择，并受 `[解锁表]` 的等级门槛限制。
4. **成长来源**：`[spin / 翻地块 / 任务]` 增加经验；`[等级经验表]` 控制升级节奏。
5. **掉落/产出**：掉落概率 `[40]`%，产出 = `[单次掉落个数]` × `[查表系数]`，写明查表字段与单位。
6. **破产调控**：开关 `[配置 ID]`、触发条件（持金/Bet ≤ N）、调控轮数与冷却、命中后按概率不中奖，并说明调控期间的余额特征（急剧下降但仍按比例调 Bet）。

## 六、经济与 RTP 口径

- 稳定期 RTP：`[90]`%（配置等级 `[N]` 起）。
- 各模块按“对投注额的 RTP 百分点”展示，横向相加 = 总经济 RTP（如总 120% = 主玩法 110% + 活动 10%），**不做归一化**。
- 分阶段给出模块占比：`[主玩法 / 建造 / 活动 / 任务 / 免费奖励 / 通行证]`；前期建造返还占比可以分多个阶段描述。
- 免费奖励：`[签到、时间礼包、在线奖励]`；通行证：`[每日任务经验 → 等级奖励]`。

## 七、付费设计

- **免费体验段**：首次付费压力出现前保持免费；首个付费点是 `[弹窗 / 破产]`，二者必须区分。
- **首充**：`[固定 $X.XX → 金币]`，不参与动态定价，首充逻辑不得改动。
- **后续阶梯**：`[$A.XX / $B.XX / …]`，逐档递增，避免新手付费过于激进。
- **付费节点**：节点表增加“何时付费、付了多少、触发原因、付费后余额/等级/进度”。
- **付费深度试算**：可用 `[余额峰值 × 50% / 75% / 100%]` 做敏感性对照，但主方案是否采用需业务确认。
- **付费后体验**：说明拉开的余额、Bet、进度差异。

## 八、模拟与输出清单

1. **节点体验表**：Spin、天/时间、Bet、余额、等级、翻地/进度、本次付费、累计付费、调控状态、体验事件。
2. **金币轨迹**：覆盖完整周期，每次操作都有数据；付费点标红；按天或阶段用底色区分；悬停可看明细。
3. **分阶段 RTP 表**：总经济 RTP + 各模块百分点贡献 + 构成条。
4. **模块单独体验表**：主玩法、建造、活动/小游戏、任务、免费奖励、通行证、长周期收集各一张。
5. **HTML 可视化 + Markdown 复算报告**：初始参数放最前面。
6. **配置表清单**：涉及 `[表名 / 配置 ID / 字段]` 及含义；程序导出配置只读核对，不直接改源。

## 十、验收标准

- [ ] 与实测或设计预期对齐（例如“实测 30–50 级通关，模拟应落在此区间”）。
- [ ] 可复算：另一位策划用同一命令得到相同结果。
- [ ] 边界与敏感性：破产、最低/最高 Bet、零值、极端玩家。
- [ ] 未知口径显式标记“待确认”，不写死成事实。
- [ ] 首充逻辑未被误改；付费主方案与试算方案分开。

## 十一、一段式速查话术

> “按 `[配置版本]` 输出一份 `[项目/竞品]` 数值体验报告：玩家 `[画像]`，初始 `[资源/汇率/启动资金]`；每日 `[X]` 分钟玩 `[N]` 天，每次操作 `[Y]` 秒；覆盖 `[模块]`；稳定期 RTP `[Z]`%，各模块按百分点展示且总和 = 总 RTP；Bet 前 `[等级]` 激进、之后按持金/150 并受解锁限制；成长来自 `[来源]`；破产调控按 `[参数]`；付费为 `[首充固定 + 后续阶梯 + 付费节点]`；输出节点体验表（分段）、逐次金币轨迹（付费点标红）、分阶段 RTP、模块单独表和 HTML 可视化；初始参数写最前面；结果可复算、可追溯；未确认项标‘待确认’。”

## 附录 A：名词表（精品拆解统一口径）

| 名词 | 定义 |
|---|---|
| 消耗段/阶段 | 按 Spin 次数、天数或等级区间划分的体验观察单元 |
| 返还 | 玩家投入后得到的金币/资源回报，含主玩法与各系统 |
| RTP 百分点 | 模块返还额 ÷ 该阶段投注额，直接以百分数相加 |
| 总经济 RTP | 主玩法 + 建造 + 活动 + 任务 + 免费奖励 + 通行证 各百分点之和 |
| 破产调控 | 命中条件后按概率调输、期间余额急剧下降的兜底机制 |
| 调输 | 调控生效时按 Bet 档位降低中奖概率 |
| 首充 | 首个付费礼包，通常固定价格与内容，不参与动态定价 |
| 付费阶梯 | 后续付费包的逐档价格与内容递进 |
| 节点体验表 | 关键 Spin/时间点上的余额、Bet、等级、进度、付费、调控快照 |
| 长周期系统 | 从开始到收集完成需要数天或更久的模块（卡包、图鉴等） |
