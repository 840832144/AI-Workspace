# CR 数值术语表

> 持续补充项目专用定义。相同概念只保留一个主术语，其余作为别名。

| 术语 | 英文/字段 | 定义 | 单位 | 权威来源 | 备注 |
|---|---|---|---|---|---|
| 期望值 | EV | 各结果价值按发生概率加权后的平均值 | 随业务 | 数值方案 |  |
| 产出 | Source | 系统向玩家账户增加资源 | 资源/时间 | 待补充 |  |
| 消耗 | Sink | 系统从玩家账户扣除资源 | 资源/时间 | 待补充 |  |
| RTP | Return to Player | 投入中长期期望返还给玩家的比例 | % | 具体玩法配置 | 不等于单局胜率 |
