# 配置变更检查清单

## 提交评审前

- [ ] 数据源、Sheet、字段和配置版本可定位。
- [ ] 所有假设都有依据或明确标为待确认。
- [ ] 概率和权重已检查总和与归一化方式。
- [ ] 货币、时间、次数、百分比等单位一致。
- [ ] 上限、下限、零值、空值、重复 ID 已检查。
- [ ] 推导脚本可以由另一位同事独立运行。
- [ ] 新旧值差异和受影响系统已列出。

## 发布前

- [ ] 策划源表与程序导出配置一致。
- [ ] 测试环境结果与推导结果在容差范围内。
- [ ] 回滚值和回滚条件已准备。
- [ ] 核心监控指标、观察周期和负责人已确认。

## 发布后

- [ ] 记录实际上线时间与配置版本。
- [ ] 对比目标值和实际数据。
- [ ] 结论、异常和后续动作写入复盘文档。
