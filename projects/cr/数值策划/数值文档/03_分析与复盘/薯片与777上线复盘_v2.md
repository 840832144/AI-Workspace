## 1. 一页结论摘要

1. **母体差异解释了“高 VIP 人少”，但不解释为参与意愿低。** 活动期登录母体为 2,098 人，其中 VIP0 1,723（82.13%）、VIP1 317（15.11%）、VIP2 18（0.86%）、VIP3+ 40（1.91%）。薯片关键奖励到达率从 VIP0 的 14.10% 升至 VIP3+ 的 85.00%；777 从 10.68% 升至 77.50%。高 VIP 是绝对人数少、相对参与率高。
2. **两活动的最大损失都发生在入口曝光之前，不在掉落环节。** 薯片未到关键奖励的 1,653 人中，1,238 人（74.89%）为“登录但无活动曝光”，258 人（15.61%）为“曝光但未打开”；777 对应为 1,248 人（70.79%）和 193 人（10.95%）。严格链路中，薯片有效 Spin→积分→道具→使用为 `584→580→563→542`，777 为 `628→624→611→575`，没有证据支持“掉落配置异常”。
3. **RTP 公式确认使用派彩口径。** `winchip` 只有正值或零，字段 `rtp` 与单局派彩倍数一致，免费局 `costbet=0`，全签名无精确重复。因此公式为 `RTP=Σ派彩/Σ付费局下注`，免费局奖励计入分子。跨 VIP 先按 PriceCheatSheet 折算同一美元尺度，活动期实际 RTP 为 `679,595.46 / 734,867.44 = 92.48%`；直接相加金币得到 79.02%，因金币价值分层不同，不作为总体判断值。
4. **95/85 配置在 Spin 数上大多匹配，但高额流水错配需要 P0 排查。** 排除 105/120 控制档和无法映射行后，档位按 Spin 数匹配 `1,345,045/1,362,445=98.72%`；按 PriceCheatSheet 归一化流水匹配率仅 `82.66%`。主要错配为“预期85、实际95”：16,802 Spin、165 人，占可比 Spin 1.23%，却占可比归一化流水 17.26%。
5. **活动上线没有形成可归因的付费提升证据。** 同一批“活动期活跃且至少一个前置窗口活跃”的 513 人中，活动期收入 $171.88，8/17 对照为 $173.59，基本持平；Spin 1,036,540，低于 8/17 的 842,476 按活跃人数换算后的强度。8/10 收入仅 $63.83，但缺少有效控制组，故只能判定为“证据冲突”。

## 6. RTP 公式验证

验证样本为主窗口内 1,691,629 条 event_7179：

- `winchip<0` 为0；正值698,869条、零值992,760条，符合派彩额而非净输赢。
- 字段 `rtp` 的分组结果与单局 `winchip/costbet` 倍数一致，说明它不是目标95/85档。
- 免费局186,433条，`costbet=0`，应把奖励纳入派彩分子、下注不纳入分母；同时单独报告免费局派彩。
- 以 `用户+时间+机器+总Spin序号+结果ID+免费标记+bet+win` 构成完整签名，精确重复0条。较短的“用户+机器+Spin序号”有重复，因为免费/奖励过程可共享序号，不能据此删除。
- `chip/start_value/slotsnetincome` 的聚合关系不满足稳定单局恒等式，不能用来重构净输赢；这是字段语义限制，不据此判断程序Bug。

最终公式：

```text
每个可比(Level,VIP)层的派彩RTP = Σwinchip / Σcostbet
总体RTP = Σ(winchip / coins_per_usd) / Σ(costbet / coins_per_usd)
```

活动期总体：毛下注 $734,867.44，派彩 $679,595.46，RTP 92.48%。原始金币直接汇总为 `31,079,280,900,513 / 39,333,184,023,000 = 79.02%`，但不同 Level/VIP 的金币价值不同，故只保留为原始字段诊断值。

## 8. 持金、破产与付费链路

已确认关系：

1. 全母体中仅2名用户出现 `controltypeint=3`，不足以建立“破产→曝光→付费”统计关系；低余额代理（任一付费 Spin 前持金小于3倍Bet）在浅/深参与用户中均存在，不能视作精确破产次数。
2. 活动期项目付费用户中，VIP0为11/1,723（0.64%），VIP3+为6/40（15.00%）；VIP1和VIP2为0。高 VIP 的项目付费率更高，不支持“高 VIP 因持金充足所以不付费”的泛化结论。
3. 薯片商品曝光524人、请求60人、成功3人。曝光→请求11.45%，请求→成功5.00%；成功3人均VIP3+、收入$169.89。损失归因另有85人明确停在“商品曝光无请求”、8人停在“请求失败”。
4. VIP0 的1,202名“两活动均无进度”用户中，931人仍有Slots Spin，说明“不推进”不能简单解释为全局不活跃，更像活动未曝光/未进入；这组仍有8名项目付费用户、收入$31.91。
5. RTP/进度只显示相关关系。VIP0归一化RTP 98.88%、VIP1 87.02%、VIP2 87.60%、VIP3+ 78.32%；分层样本结构和高额少数用户差异很大，不能据此断言低RTP导致退出。

当前无法可靠输出最低/结束持金、最大回撤、精确破产次数与首次破产时间：event_7179 的 `chip/start_value/slotsnetincome` 不满足稳定单局恒等式，且受控商城事件无权限。报告使用起始登录持金和低余额代理，并明确证据边界。

高低 VIP 的直接解释：

- VIP3+ 薯片：40人中38曝光、36打开、34到关键奖励。未到奖励的6人可对账为无曝光1、曝光未打开2、Slots无进度1、商品曝光无请求2。35人看到薯片商品、6人发起请求、3人成功；所以高VIP的主要事实是“参与深、商品请求少”，不是“奖励不吸引而未参与”。
- VIP3+ 777：40人中37曝光、35打开、31到关键奖励、28到轮次里程碑。未到奖励的9人为无曝光3、曝光未打开2、Slots无进度1、使用后未到里程碑2、低余额代理1。样本很小，不据此调整全局奖励。
- VIP0 薯片：1,480人未到奖励，其中无曝光1,193、曝光未打开186、商品曝光无请求45、请求失败8；项目付费仅11人，活动支付成功0人。入口和支付可观测性优先于奖励。
- VIP0 777：1,539人未到奖励，其中无曝光1,201、曝光未打开132、使用未到里程碑59、低余额代理100。中段成本影响存在，但仍远小于入口损失。

## 9. 薯片专项分析

1. **事实：入口是主问题。** 853/2,098曝光、595打开；未获关键奖励用户中90.50%停在“无曝光/曝光未打开”。这比积分→道具→使用的严格损失38人高一个数量级。
2. **事实：掉落没有异常证据。** 严格链路 `584有效Spin→580积分→563道具→542使用`；配置概率20%不能用积分总量/Spin数复算，缺关联键时不宣称已独立验收命中率，但不建议调整掉落。
3. **事实：深度随VIP提高。** 关键奖励/在线母体：VIP0 14.10%、VIP1 49.21%、VIP2 66.67%、VIP3+ 85.00%；高VIP样本小但方向一致。
4. **事实：商品链路损失大。** 524曝光→60请求→3成功，主要应先查事件/支付链路和商品表达，而不是先提高奖励。
5. **推断：现金奖励规模不是首要瓶颈。** 现金等价奖励近似$8,294.31，且深度用户领取频繁；未进入用户没有机会感知奖励。只有修复入口与支付可观测性后，才有条件验证礼包价值或奖励吸引力。

## 10. 777 专项分析

1. **事实：入口仍是最大损失。** 846曝光、653打开；未获关键奖励者中81.74%停在无曝光/曝光未打开。
2. **事实：中后段存在次级压力。** 使用575→关键奖励331，互斥归因中101人“使用但未到里程碑”、143人“持金不足代理”，合计13.84%的损失母体。
3. **事实：VIP越高，到达关键奖励的比例越高。** VIP0/VIP1/VIP2/VIP3+分别10.68%/34.70%/55.56%/77.50%；不支持“高VIP奖励不吸引所以参与少”。
4. **事实：设计完整成本高于V1旧模拟。** trunk参考口径为95档$89.60、85档$134.40，现金奖励$30.08；不能沿用把777积分效率当薯片的$67.20/$100.80旧值。
5. **推断：成本可列为P2实验项，但不是P1主因。** 先解决入口，再针对原因8/9用户做轮次成本或中段反馈实验；当前不能直接下调全局成本。
