# 竞品与体验分析

## 当前主题

- 弹球公园数值体验：体验节奏、奖励密度、关卡/局次成本和可迁移机制。
- Tycoon 翻地块：建造/翻地块循环、解锁节奏和资源消耗曲线。

## 记录模板

| 字段 | 要求 |
|---|---|
| 竞品与版本 | 产品、地区、版本号、体验日期 |
| 样本 | 账号阶段、局数/时长、付费状态 |
| 原始观察 | 只写可复核的界面、数值和行为 |
| 推断 | 与原始观察分开，标注置信度 |
| 可迁移点 | 写清适用的 CR 玩家层级和系统 |
| 验证 | 对应 CR 源表、测试方法和结果 |
| 结论 | 采用、调整后采用或不采用 |

本地相关源表为 `建造数值.xlsx`、`建造数值体验表.xlsx` 和
`弹球quest数值 (2).xlsx`。竞品 Sheet 不得直接复制为程序配置。
