# 数值文档

| 目录 | 用途 |
|---|---|
| `00_规范` | 模板、术语、评审和变更检查清单 |
| `01_系统设计` | 经济、成长、奖励、概率等长期系统 |
| `02_玩法与活动` | 玩法、活动、Quest、礼包等阶段性设计 |
| `03_分析与复盘` | 数据分析、版本对比、上线复盘 |
| `04_飞书归档` | 从飞书导入的原始正文、附件说明与来源信息 |
| `99_归档` | 已废弃或仅供历史追溯的文档 |

文档命名建议：`YYYY-MM-DD_系统或活动_主题_vN.md`。有效方案必须写明负责人、版本、适用配置版本和数据源。

## 阅读入口

1. 先在对应业务区域阅读整理后的方案说明。
2. 需要追溯原文时进入 `04_飞书归档`。
3. 需要定位 Excel 时查看 `../知识库/策划源表导航.xlsx`。
4. 需要核对程序落地时直接只读目标 `dev` 或 `trunk`，并记录 SVN URL 与 revision。
