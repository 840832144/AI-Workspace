# CR 飞书文档归档

本目录保存从飞书实际导入的 CR 文档正文，不是链接索引。

## 目录

- `公司知识库`：公司 `CashRoyal` 知识库中的正式资料。
- `个人文档`：个人区中已确认属于 CR、且不在公司知识库重复出现的资料。
- `附件`：飞书页面中的附件；若与 `数据源/策划源表` 内容相同，则使用仓库相对路径引用已有文件，不重复保存。

## 导入规则

1. 只导入 Cash Royal；101、Spades、Bingo 等项目不进入本目录。
2. 保留飞书标题、所有者、最后修改时间和原始链接作为溯源元数据。
3. 正文、附件和交叉引用全部使用仓库相对路径，不记录任何成员电脑路径。
4. 飞书后续变更需重新导入并更新“导入日期”和变更说明。
