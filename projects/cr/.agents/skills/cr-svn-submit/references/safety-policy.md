# SVN 自动提交安全策略

## 默认行为

- 不带 `--execute` 时仅演练，不改变工作副本或远端仓库。
- 执行提交前更新工作副本，并以 `postpone` 保留冲突现场。
- 使用系统 SVN 凭据缓存；仓库内不保存账号、密码或令牌。
- 只处理传入的 SVN 工作副本根目录，拒绝工作副本外路径。
- 中文提交说明统一使用 UTF-8 日志文件和 `--encoding UTF-8 --file`；不得直接在终端使用中文 `svn commit -m`。
- Windows PowerShell 5 会把 UTF-8 无 BOM 脚本中的中文常量按系统代码页误读；不得用此类脚本生成中文提交说明，优先使用 Python 3 工具。

## 自动中止

- 文本、属性或树冲突。
- 文件从磁盘缺失但未执行 `svn delete`。
- Excel 临时文件、Python 缓存、日志或其他项目命名文件。
- `validate_repository.py` 返回非零。

## 显式授权

| 场景 | 参数 | 使用条件 |
|---|---|---|
| 提交已登记删除 | `--allow-delete` | 已核对删除清单 |
| 跳过仓库更新 | `--skip-update` | 已确认版本最新或网络不可用 |

缺失文件不能通过 `--allow-delete` 绕过；先恢复文件或明确执行 `svn delete`。

## 提交后日志核验

- 从提交输出或工作副本 revision 取得实际版本号。
- 执行 `svn log -r <revision>`，确认作者符合用户指定账号，中文日志完整且无乱码。
- 日志作者或文字不符合预期时，明确报告，不得用新的无关提交掩盖。
