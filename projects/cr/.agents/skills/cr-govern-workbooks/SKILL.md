# CR 策划源表治理

## 工作流

1. 先读取 `数值策划/知识库/策划源表导航.xlsx`、`数值策划/知识库/工作簿结构.json` 和相关业务文档。
2. 按 `references/sheet-classification.md` 对 Sheet 分类，记录推荐入口和版本边界。
3. 优先通过导航和文档消除阅读混乱；不要为“整齐”批量重写公式、数值、Sheet 顺序或全表样式。
4. 需要修改工作簿时，先渲染查看现状，保存独立修改版，对比公式、名称、关键输出和视觉结果。
5. 引用结论时写明仓库相对文件、完整 Sheet 名、版本/日期、输入假设和输出字段。
6. 更新 `策划源表导航.xlsx` 和对应业务文档，再重建工作簿目录。
7. 运行仓库校验，确认工作簿可读取且没有临时文件。

## 禁止事项

- 不把程序 `dev` / `trunk` 配置复制进资源库，也不在源表治理任务中修改程序配置。
- 不把备份、废弃、竞品或 `Sheet1` 自动认定为当前口径。
- 不在未确认负责人和版本的情况下覆盖原源表。

## 完成标准

- 新策划能从导航找到入口、配置页和历史页。
- 当前口径与追溯资料分开。
- 关键公式和输出未因整理发生非预期变化。
