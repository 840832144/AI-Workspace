# Sheet 分类

| 类型 | 识别信号 | 使用规则 |
|---|---|---|
| 概览/方案 | 总览、概览、说明 | 作为工作簿入口 |
| 输入/参数 | 参数、Bet、道具 ID、源数据 | 标明单位和来源 |
| 推导/计算 | Calculate、膨胀、权重、CheatSheet | 保留公式和中间值 |
| 体验/验证 | 数值体验、用户分布、测试体验 | 标明版本、样本和判断标准 |
| 配置/输出 | 程序表名、Cfg、Reward、outPut | 必须能反查推导 |
| 历史/参考 | 旧版、备份、废弃、日期旧版本、竞品、Tycoon | 原则上只读 |

统一阅读顺序：

`概览 → 输入 → 推导 → 体验 → 配置输出 → 程序快照校验`
