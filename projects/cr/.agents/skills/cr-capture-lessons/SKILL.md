# CR 问题经验沉淀

## 核心规则

- 遇到非日常问题、失败尝试、阻塞、用户纠正或高风险决策时，任务结束前执行本 Skill。
- 无论最终状态是已解决、部分解决或未解决，都记录事实、证据和下一步。
- 只沉淀可复用经验；不记录无信息量的普通命令失败。
- 不写入账号密码、令牌、隐私、线上敏感明细或本机临时路径中的秘密。

## 工作流

1. 完整读取 `references/lessons.md`，检索是否已有相同问题，优先补充旧条目而非重复新增。
2. 汇总现象、影响范围、已确认事实、待确认推测、尝试过的方法及每次结果。
3. 将状态标记为“已解决 / 部分解决 / 未解决”，不得把绕过方案写成根因修复。
4. 按经验库模板新增或更新条目，附文件、命令、错误码、revision 等可核验证据。
5. 若结论属于某个业务 Skill 的必备护栏，在该 Skill 中增加简短强制规则，并让详细经过只保留在经验库中。
6. 运行相关语法、业务和仓库校验；校验受存量问题阻塞时，记录阻塞和用户授权边界。

## 质量标准

- “事实 / 推测 / 待确认”边界清楚。
- 失败尝试及失败原因被保留，避免其他 Agent 重复踩坑。
- 解决方案包含适用条件、验证方式和回滚或后续动作。
- 未解决条目有明确负责人条件或下一次应执行的检查。
- 经验能被不了解原任务的其他策划或 Agent 独立复用。
