# CR 资料范围与落库位置

## 纳入

- 公司 `CashRoyal` 知识库中的系统、玩法、数值、调控和竞品资料。
- 个人区中标题、正文或所在空间能确认属于 CR 的资料。
- 与 CR 源表直接对应的附件。

## 排除

- 101、Spades、Bingo、Texas Poker 及其他项目资料。
- 仅有标题、正文未读取成功的候选资料。
- 混有其他项目侧栏且无法裁净的页面截图。
- 账号、令牌、个人隐私和本机路径。

## 目录

- `04_飞书归档/公司知识库`：公司空间原文。
- `04_飞书归档/个人文档`：个人区 CR 原文。
- `01_系统设计`：当前长期系统口径。
- `02_玩法与活动`：当前玩法和活动口径。
- `03_分析与复盘`：竞品、体验和复盘结论。
