# 数值推导与评审流程

## 1. 定义问题

- 写清要优化的玩家体验或业务指标。
- 指定玩家分层、时间窗口、版本和目标容差。
- 区分需要求解的变量与固定约束。

## 2. 建立输入表

每个参数记录：业务名、字段名、值、单位、来源、可调范围、是否已确认。不要在单位未统一前计算。

## 3. 分步推导

按“输入 → 转换 → 中间量 → 输出”拆解。复杂公式使用具名中间变量，Python 输出关键步骤。概率类结果同时计算理论值和模拟值时，记录随机种子与模拟次数。

## 4. 交叉校验

- 手算一个小样本。
- 与旧配置或基准版本对比。
- 检查总和、守恒关系和单调性。
- 测试零值、最大值、最小值、缺失值和重复项。
- 对关键假设做 ±10% 或业务合理范围的敏感性测试。

## 5. 输出建议

同时给出当前值、建议值、改动比例、影响人群、预期指标、风险、回滚条件和监控周期。将“数学上成立”和“业务上建议”分开表达。
