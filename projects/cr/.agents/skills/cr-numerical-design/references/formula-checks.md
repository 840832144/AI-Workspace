# 常用公式与检查

## 概率与权重

```text
归一化概率 p_i = w_i / Σw
期望值 E[X] = Σ(p_i × x_i)
方差 Var(X) = Σ(p_i × (x_i - E[X])²)
```

检查权重是否允许为零或负数、总和是否溢出、抽取是否有保底/不放回/动态权重。不要把权重直接当百分比。

## 经济产销

```text
净产出 = 总产出 - 总消耗
存量变化 = 期初存量 + 净产出
覆盖天数 = 当前存量 / 日均净消耗
```

分别观察均值、中位数和玩家分层，避免被少量高价值玩家扭曲。

## 成长节奏

```text
累计需求(L) = Σ(单级需求_i), i=1..L
预计耗时 = 累计需求 / 单位时间有效产出
```

检查曲线连续性、局部突增、解锁节奏、资源并行消耗和付费加速影响。

## 配置差异

```text
绝对变化 = 新值 - 旧值
相对变化 = (新值 - 旧值) / 旧值
```

旧值为零时不计算相对变化，改为标记“从零新增”。
