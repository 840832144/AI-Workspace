# CR 数值策划

## 任务路由

- 资料导入、飞书归档和项目筛选：使用 `cr-ingest-knowledge`。
- 策划源表入口、版本页和历史页整理：使用 `cr-govern-workbooks`。
- 程序配置核对：直接只读目标 `dev` 或 `trunk` 工作副本，先用 `svn info` 锁定 URL 与 revision。
- 经济、成长、概率、奖励和玩法数值推导：继续执行本 Skill。

## 核心工作流

1. 读取根目录 `AGENTS.md`、数值文档规范和 `数值策划/知识库/数据目录.md`。
2. 从知识库目录定位候选工作簿，再打开具体源表确认 Sheet、字段、单位、版本和公式。
3. 明确问题、目标指标、玩家分层、时间窗口和不在本次范围内的事项。
4. 建立输入、假设和约束表；把未知口径标记为“待确认”，不得自行补成事实。
   从体验阶段落正式配置前，必须显式确认体验阶段与配置主键、轮次、状态和触发机制的映射；无法一一映射时停止写入和提交，不得按同名字段猜测或只落奖励子集。
5. 使用公式和 Python 3 推导，保留关键中间结果和业务注释。
6. 检查零值、上下限、概率和、重复 ID、单位换算、极端行为和关键参数敏感性。
   校验掉落概率时，分子必须是命中掉落的唯一行为数，分母必须是符合条件的行为数；积分或奖励总量除以行为数只能称为平均产出，禁止作为掉落命中率。
7. 用 `数值策划/数值文档/00_规范/数值方案模板.md` 交付结论，写明风险、回滚条件和监控指标。
8. 运行仓库目录构建与校验工具，确认产物可被其他人复跑。

## 资料选择

- 需要判断资料权威性或来源关系时，读取 `references/source-policy.md`。
- 需要完整推导与评审步骤时，读取 `references/derivation-workflow.md`。
- 需要概率、经济或成长公式检查时，读取 `references/formula-checks.md`。
- 报告声明使用某个程序环境配置时，必须直接以该环境的版本化配置为准，记录 `dev` / `trunk`、SVN URL 与 revision，并按玩法依赖成组核对概率、门槛、奖励和状态切换表；策划源表仅作推导与交叉检查，发现差异不得混算。

## 代码要求

- 使用 Python 3 和类型标注，优先标准库。
- 将业务假设放在具名参数、配置文件或输入表中，不写无法解释的数字常量。
- 在输出中同时给出运行命令、输入文件、输出文件和误差容限。
- 原始 Excel 只读；修改版输出到独立路径。

## 完成标准

- 结论能追溯到具体文件、Sheet、字段和版本。
- 另一位制作人或数值策划能从文档理解推导，并独立运行脚本得到同一结果。
- 关键边界、敏感性、配置差异、风险和验收指标已明确。
- 未确认信息和推测均有显式标记。
