# CR Design Git 审阅副本说明

## 用途

本仓库是 Cash Royal 数值策划 SVN 工作副本的私有 Git 审阅镜像，供 GPT、Codex 和策划协作者检查项目逻辑、目录结构、数值推导方法、文档组织和 Agent 协作规则。

## 快照口径

- 快照日期：2026-08-28。
- 基线：CR Design SVN trunk 工作副本，基线 revision 为 `r6429`。
- 包含：SVN 已纳管文件、快照时工作副本中的有效修改，以及尚未纳管的挖矿/拳击验收报告生成脚本。
- 本次只建立 Git 审阅镜像，不改变 SVN 工作副本，不向 SVN 提交。

## 主动排除

以下内容不会进入 Git：

- SVN 元数据；
- Agent 临时目录和一次性输出；
- Python 虚拟环境、缓存与日志；
- HuuugeCollector 本机运行数据、原始采集、可复现二进制和安装包；
- 凭据、令牌、用户隐私与机器本地密钥。

## 审阅入口

1. `README.md`：CR 数值策划资源库总览。
2. `AGENTS.md`：项目协作与数据安全约束。
3. `.agents/skills/`：数值推导、资料导入、源表治理、SVN 提交和问题沉淀工作流。
4. `数值策划/数值文档/`：数值规范、系统设计、活动方案与复盘。
5. `数值策划/工具/`：目录构建、仓库校验、模拟与报告生成脚本。
6. `HuuugeCollector/`：独立的数据采集与结构化分析子项目；先阅读其中的 `AGENTS.md`、`CONTRIBUTING.md` 和 `CURRENT_STATUS.md`。

## 真相源边界

- CR 数值策划日常协作和正式提交仍以公司 SVN 为准。
- 此 Git 仓库主要用于跨 Agent 审阅与结构分析；后续若形成修改建议，应回到对应工作流验证后再落地。
- 原始线上数据、账号信息和本机运行产物不应补传到本仓库。
