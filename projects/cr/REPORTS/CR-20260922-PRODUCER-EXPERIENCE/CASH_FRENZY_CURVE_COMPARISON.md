- Parent Task: TASK-0036
- Status: Changes Requested / User Approved
- Date: 2026-09-21
- Scope: 只生成Cash Frenzy竞品曲线展示Excel；不改CR r7013配置，不修改CF_collect，不采集新数据

## 目标

生成一份独立的 `CashFrenzy_数值曲线对照.xlsx`，**可见结构、页签顺序、折线图组织与当前CR《CR_9.22_数值曲线展示_r7013_v2.xlsx》保持一致**，用于制作人逐页并排比较CR与Cash Frenzy成长曲线。

本轮不把CR与Cash Frenzy强行叠在同一条图中；先做完全同构的Cash Frenzy版本，确保两个工作簿可以一一对应比较。若后续User需要双游戏同图overlay，再作为后续修改。

## 数据来源与证据优先级

1. 第一优先：公司历史正式数值体验资料中的旧 `CashRoyal数值.xlsx`，重点读取 `cashFrenzy等级` 及与其直接关联的VIP、Bet、档位膨胀、升级奖励/返还数据。
2. 第二优先：同一历史“数值推导/数值体验”资料中已存在的Cash Frenzy竞品表或附件；只复用已有竞品数据与原计算口径。
3. Git中已有证据确认旧 `CashRoyal数值.xlsx` 包含 `cashFrenzy等级` Sheet；旧值此前仅作为竞品/结构参考，本任务由User明确授权将其中**Cash Frenzy竞品数据**用于新竞品曲线表。
4. 多版本冲突时，优先使用与当前历史数值体验表配套、来源最完整的一版，并在受控验证摘要中记录文件名/Sheet/日期或版本；不要自行混合多个版本。
5. 不使用CR r7013值填补Cash Frenzy缺口；不使用CF_collect运行数据、外部Web或猜测补齐历史竞品表没有的字段。
6. 若某条曲线的必要输入确实不存在，保留该页同结构并明确“来源不足 / N/A”，同时列出缺失字段；不得拟合、插值或借用CR规则。

## 可见页签：固定5页，顺序必须一致

### 1. VIP_消费门槛

折线图：**消费门槛（美金） / VIP等级**

表列：
- VIP等级
- 累计消费门槛（USD）
- 本级新增消费（USD）

口径：
- 直接沿用Cash Frenzy历史表中的VIP消费/经验换算口径。
- 如果历史表只有VIP点而没有美元换算，先寻找同一资料内明确的点数/美元关系；找不到则不使用CR的$1=100点规则。

### 2. VIP_膨胀系数

折线图：**膨胀系数（百分比） / VIP等级**

口径必须是**绝对膨胀**，不是相邻环比：
- 基准 = Cash Frenzy VIP1累计消费门槛 = 100%
- 绝对膨胀系数 = 当前VIP累计消费门槛 / VIP1累计消费门槛
- 例如300%代表当前累计消费门槛是VIP1的3倍

表列：
- VIP等级
- 绝对膨胀系数（VIP1=100%）
- 累计消费门槛（USD）
- 本级新增消费（USD）

### 3. 等级_升级消耗

折线图：**升级消耗美金 / 等级**

要求：
- 使用Cash Frenzy历史表自身的等级升级成本口径。
- 优先直接复用已有“升级消耗美金/升级成本”结果；若需要从Spin/Bet/RTP推导，必须使用Cash Frenzy历史资料本身明确的Bet、经验、RTP/净耗规则。
- 不允许套用CR“等级统一95% RTP”规则。
- 保留全部逐级点，不只画里程碑；必须能看出阶段跳档、回落与总体增长形态。

表列：
- 等级
- 升级机器理论净耗（USD）或历史表定义的等价升级消耗USD
- 升级奖励（USD）
- 升级净成本（USD）

若历史资料中的“消耗美金”定义不是机器理论净耗，前台必须使用原资料准确命名，并在页头说明，不能偷换成CR口径。

### 4. 等级_Bet曲线

同一张折线图放两条线：
- **最大Bet / 等级**
- **推荐Bet（按1美金对应Bet） / 等级**

表列：
- 等级
- 最大Bet（原货币）
- 最大Bet（统一缩放单位，如百万金币/筹码）
- $1等值推荐Bet（原货币）
- $1等值推荐Bet（同一缩放单位）
- 最大Bet折算USD（如来源支持）

要求：
- 两条线必须使用同一纵轴单位，便于直接比较。
- 最大Bet取Cash Frenzy该等级真实可用/解锁上限。
- 推荐Bet按Cash Frenzy历史表自身的“$1对应Bet/金币价值”口径还原。
- 如果旧表已有正式推荐Bet列，优先使用正式列；只有明确证据时才按$1价值换算。
- 不使用CR最大Bet或金币价值档位补齐。

### 5. 等级_升级消耗返还

折线图：**升级消耗返还 / 等级**

口径：
- 升级消耗返还率 = 本级升级奖励USD / 本级升级消耗USD
- 分母必须与“等级_升级消耗”页完全同口径。
- 奖励只计历史Cash Frenzy资料中可明确美元化的升级奖励；无法计价的奖励单独记录，不强行估值。

表列：
- 等级
- 升级消耗返还率
- 升级消耗（USD）
- 升级奖励（USD）
