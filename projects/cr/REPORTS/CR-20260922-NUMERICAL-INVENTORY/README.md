## 公式和分母

- 同一有效池：`p_i=w_i/sum(w)`，`E[X]=sum(p_i*x_i)`。状态、单位、枚举和组键先固定；概率不闭合不擅自归一。
- 精确档参考 `USD Bet=金币Bet/同档一配置美元金币`。User常规规则保持>1为85%、<1为95%，等于1待确认；配置价值不代表实付或实际机器档位。
- 若独立固定概率p、每次命中固定积分g、阶段从0起、升级清零且每次至多升一阶段：`E[Spin]=ceil(T/g)/p`，`E[毛下注]=E[Spin]*金币Bet`。完整获取矩阵与阶段表分开，示例不是玩家行为分布。
- 毛下注W、机器返奖R、机器净耗`C=W-R`分别记录；只有RTP确定适用时，条件`E[C]=W*(1-RTP)`才成立。活动金币奖励占毛下注、占机器净耗、同资源返还以及实付不混用。期望量之比不等于逐玩家比率的期望。
- 多活动共享一次Spin时，W只记一次。通常同时两个但组合未定，本轮不默认四个全开、不选组合/排期、不设优化目标。
- VIP累计门槛取差，等级Spin/经验分开累计；非累计Pass门槛相加，累计门槛同章内取差，空门槛保持缺口。
- 源表缓存是文件载值，不等于独立复跑源公式。共享公式从属格、外链、缺缓存和Excel错误缓存分别记录；新建复算公式单独验证。
