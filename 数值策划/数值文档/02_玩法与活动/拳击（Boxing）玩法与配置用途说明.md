# 拳击（Boxing）玩法与配置用途说明

> 状态：拳击当前配置大概率仍是测试数据，本文按需求玩法沉淀“玩法闭环 + 每张表干什么用”，数值待需求定稿后再改。

## 一、玩法闭环

### 1. 道具获取（老虎机掉落）

- 复用活动通用掉落，只改数值。
- 玩家在老虎机 Spin 时有概率掉落「活动道具经验」；FreeSpin / Respin 不掉经验。
- 经验条涨满 100% 获得 1 个活动道具；先按“不清零”计算（溢出经验继续累计，不丢弃）。
- 下注（Bet）越高，单次掉落的经验越多。

### 2. 核心玩法：消除方块收集奖励

- 三条独立轨道，不同消耗与宝石：
  - 高级轨道（紫色金属方块）：每次消耗 10 道具，概率产出粉色宝石。
  - 中级轨道（银质方块）：每次消耗 5 道具，概率产出蓝色宝石。
  - 初级轨道（木质方块）：每次消耗 2 道具，概率产出绿色宝石。
- 每条轨道横向 8 个方块，每格随机生成 2~3 个奖励。
- 点击红色圆形按钮，手套横向弹出击碎轨道上的方块并获得奖励。
- 需要配置：各轨道物品掉落概率表、宝石掉落权重、阶梯式难度（关卡提升、收集难度增加）。

### 3. 奖励内容

- 即时奖励：金币、建造币，击中后直接飞向对应栏。
- 宝石收集（核心进度）：
  - 三种宝石：绿色、蓝色、粉色。
  - 同一颜色收集满 3 个，立即弹窗发对应档大奖；领奖后该颜色槽清空，可重复收集但难度变难。
  - 不同轨道的宝石相互独立，不混合计算。

### 4. 商业化与礼包

- 道具礼包：复用活动通用道具礼包，只改 UI 和奖励数值；道具不足点抽奖时弹出，或点击道具入口主动查看。
- BP 通行证：复用活动通用 BP，改 UI 资源和数值；进度方式改为「每消耗 1 个活动道具，BP 经验 +1」。

## 二、每张配置表是做什么用的

### 1. 拳击专属配置

| 表 | 干什么用 |
|---|---|
| `QuestBoxingStageReward` | 每个轨道、每个格子的奖励随机逻辑：`Turn`（轮次循环）、`orbit`（轨道）、`Weight`（权重）、`MaxNum`（每格最多奖励数）、奖励类型/id/数量；`999` 表示宝石收集物（对应 `QuestJackpotCfg`）。每个轨道单独计算轮次。 |
| `QuestBoxingJcakpot` | 宝石大奖配置：按 `Turn`（轮次）+ `Orbit`（轨道）配「消耗道具数、需要收集的宝石 id 和数量、集满后的奖励」。体现三轨道 2/5/10 消耗与绿/蓝/粉三色宝石，`Turn` 递增对应「重复收集难度/奖励阶梯」。 |
| `QuestBoxingPass` | 拳击 BP 通行证：免费/付费线（`category`）、关卡（`levelId`）、升级经验（`LevelExp`）、各节点奖励（`rewardType/Id/Num`）。需求口径为「每消耗 1 个道具 BP 经验 +1」，当前为测试数据待改。 |

### 2. 掉落与兑换（questType=8，共用通用表）

| 表 | 干什么用 |
|---|---|
| `QuestPickGet` | 通用掉落表：按活动类型 + bet 档配置掉落概率（千分比）和单次掉落的积分/经验值；拳击用 questType=8。 |
| `QuestPointsCheatSheet` | 把「Spin 的 bet」换算成「活动积分」：按活动类型、等级、VIP 给出积分系数；`Id` 对应 `QuestPickGet.Id`。 |
| `QuestGetLevel` | 积分累计升级：每一级需要多少积分、达到后给多少道具/经验，以及上限墙；拳击用 questType=8（当前只有占位行，测试数据）。 |
| `QuestInitItem` | 活动开启时发放的初始道具数量、及活动期间一个道具兑换的金币数；按 questType 配。 |
| `QuestPicksDifficulty` | 掉落/兑换的阶梯难度：按 VIP/活动类型给「经验倍数」和「VIP 金币奖励倍数」，用于关卡提升、收集难度增加的数值档。 |

### 3. 宝石大奖定义

| 表 | 干什么用 |
|---|---|
| `QuestJackpotCfg`（Type=8 拳击） | 定义拳击三种宝石（绿/蓝/粉）的收集物 id、收集数量与基础奖励，供 `QuestBoxingJcakpot` 的 `GemItemId` 引用。 |

### 4. 商业化与礼包

| 表 | 干什么用 |
|---|---|
| `QuestItemPack` | 活动通用道具礼包：道具包的 gp/iap 商品 id、参考价格、道具数量；拳击复用此表，改 UI 与奖励数值。 |
| `QuestBoxingPass` | 拳击 BP 数值（见上）。 |
| `QuestBPTask` / `CommonBPLevel` / `CommonBPLevelCondition` / `CommonBPPrice` / `BPReward` 等 | 通用 BP 通行证的等级、条件、价格、奖励结构；拳击复用通用 BP，只改 UI 资源与数值。 |

### 5. 活动总控、通用资源与消耗成本

| 表 | 干什么用 |
|---|---|
| `Activity`（id=1035） | 拳击活动总开关、时间档期、解锁条件、弹窗、图标。 |
| `SysUnlock` | 拳击功能的解锁条件。 |
| `PopControl` / `PopList` | 拳击相关弹窗（开启通知、领奖弹窗等）。 |
| `ModuleNames` / `Item` / `LanguageDesc` | 模块、道具、多语言名称与资源引用。 |
| `PriceCheatSheet` | 价格基准表：各等级/VIP 下 1 美金金币值，用于 17 型奖励金额查表。 |
| `SlotsCasinoBetList` | bet 档位列表，用于把“1 美金门槛”映射到 betIndex。 |
| `SlotsCasinoResultSwitchStrategy` | 按机器/等级/VIP/bet 切换 Slots 的 RTP（95%/85%），决定玩家 Spin 的净消耗，间接影响拳击掉落成本。 |
