# 薯片与幸运7（777）玩法与配置用途说明

> 本文只说明“玩法是怎么转起来的”和“每张配置表管什么、干什么用”，不列具体数值。
> 需要具体数值时，再按表名去 dev / trunk 的 `ExcelConfigExport/Excel` 目录查当前导出。

## 一、两个活动的玩法闭环

### 薯片

玩家 Spin（老虎机）→ 按概率掉落活动积分 → 积分累计到等级后给薯片道具 → 开薯片盒 → 盒子里随机出「金币 / Pass 奖票 / 四档 Jackpot 收集物」；收集满某一档 Jackpot 发对应大奖。Pass 分免费线和付费线。

### 幸运7（777）

玩家 Spin → 掉落积分 → 积分换骰子 → 消耗骰子在一个三圈棋盘上逐格抽奖，每格只中一次、即时发奖；现金按外/中/内圈兑现；樱桃和 777 是收集物，收集满 3 个在轮末发大奖。

## 二、每张配置表是做什么用的

### 1. 活动总控

| 表 | 干什么用 |
|---|---|
| `Activity` | 活动的总开关：活动 id、开启/结束时间、解锁条件、弹窗、图标、跳转等；薯片 id=1033、777 id=1034 |

### 2. 掉落与积分（两个活动共用）

| 表 | 干什么用 |
|---|---|
| `QuestPickGet` | 控制玩家 Spin 时掉落活动道具的概率（掉率） |
| `QuestPointsCheatSheet` | 把“Spin 的 bet”换算成“活动积分”：按活动类型、玩家等级、VIP 给出积分系数；等级/VIP 越高金币越膨胀，用这里保证同 1 美金的进度一致 |
| `QuestGetLevel` | 积分累计升级：每一级需要多少积分、达到后给几个道具（薯片或骰子），以及最后一档的“上限墙”——决定活动能推多深 |
| `QuestInitItem` | 活动开启时给玩家的初始道具数量 |
| `PriceCheatSheet` | 价格基准表：各等级/VIP 下 1 美金对应的金币值；也用于给 17 型（美金金币）奖励查金额 |

### 3. 薯片开盒与奖励

| 表 | 干什么用 |
|---|---|
| `SnackDropItemCfg` | 开盒掉落表：一个薯片盒里出「重置道具 / Pass 奖票 / 金币 / 四档 Jackpot」各自概率和数量，并按剩余盒子数、幸运值分档 |
| `SnackPassReward` | 薯片 Pass 的免费线和付费线各节点奖励（付费 Pass 另收 $4.99） |
| `SnackAddLuck` | 开盒的“幸运值”档位：控制玩家进入更高奖励档的门槛/进度 |
| `QuestJackpotCfg` | 四档 Jackpot（mini/minor/major/grand）的收集门槛和奖励金额（Type=4 是薯片） |
| `SnackItemPack` | 薯片道具的打包/礼包相关配置（具体用途以表内注释为准） |

### 4. 777 棋盘与奖励

| 表 | 干什么用 |
|---|---|
| `StrikeLucky` | 棋盘格子配置：每格属于第几轮、外/中/内哪一圈、命中权重、格子里给什么（金币/钻石/道具/美金金币/收集物）、前 N 轮是否必中 |
| `StrikeLuckyRound` | 每一轮的规则：三圈各自消耗多少骰子、樱桃和 777 各要收集几个、收集满发什么奖励 |

### 5. Slots RTP 切换（决定活动消耗成本）

| 表 | 干什么用 |
|---|---|
| `SlotsCasinoResultSwitchStrategy` | 按机器、等级、VIP、bet 档把 Slots 的 RTP 切到 95% 或 85%；bet 达到门槛就切 85%，影响玩家的净消耗（流水） |
| `SlotsCasinoBetList` | bet 档位列表：用来把“1 美金门槛”对应到具体 betIndex |
| `SlotsCasinoCommResultStrategy<机器>_<N>` | 每台机器的结果策略文件，`_N` 对应不同 RTP 档（`_2` 即 85% 档） |

## 三、几个容易混淆的概念

- 「掉落积分」和「兑换道具」是两件事：积分先按 bet 掉落，再在 `QuestGetLevel` 里累计换道具。
- 「活动进度」不等于「流水」：低 RTP 档（95%）净消耗小、进度慢；高 RTP 档（85%）净消耗大、进度快。
- 「净消耗」和「毛消耗」：净消耗 = 毛消耗 × 净损率；报告里的里程碑、付费缺口都按净消耗算。
- 「圈/轮」在 777 里只是进度里程碑，不是发奖时点；发奖是逐格即时发生的。
